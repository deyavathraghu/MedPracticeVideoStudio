# MedPractice Video Studio

A beginner-friendly app for planning faceless healthcare videos.

## Features
- Healthcare topic input
- Instagram Reel and YouTube format selection
- Four-scene storyboard
- Narration and visual directions
- Downloadable TXT output
- Medical review reminder

## Run locally

Install dependencies:

    python -m pip install -r requirements.txt

Start the app:

    streamlit run app.py

## Safety

Review medical claims and safety advice against reliable sources.
Have healthcare content reviewed before publication.
Do not enter patient-identifiable information.
